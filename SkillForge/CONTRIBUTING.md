# Contributing to SkillForge

Thank you for your interest in contributing to **SkillForge**! We welcome contributions from developers of all skill levels.

---

## 📋 Code of Conduct

Please be respectful, constructive, and collaborative in all issues and pull requests.

---

## 🚀 How to Contribute

### 1. Fork & Clone
```bash
git clone https://github.com/ayushkumarjha1/SkillForge.git
cd SkillForge
```

### 2. Create a Branch
```bash
git checkout -b feature/your-feature-name
```

### 3. Install & Run Locally
```bash
npm install
cp .env.example .env
npm run dev
```

### 4. Code Standards
- Keep CSS clean and use variables from `public/css/style.css`.
- Ensure all views maintain responsive styling across desktop and mobile.
- Test your changes locally before submitting.

### 5. Commit Conventions
Use clear, conventional commit messages:
- `feat: add new AI mock interview category`
- `fix: resolve chart.js tooltip formatting on mobile`
- `docs: update system architecture diagram`
- `refactor: optimize database query parallelization`

### 6. Submit a Pull Request
Push your branch to GitHub and open a PR with a clear summary of your changes and screenshots if UI changes are included.
